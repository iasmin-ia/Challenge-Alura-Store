📊 Análise de Desempenho das Lojas – Alura Store
📌 Sobre o Projeto

Este projeto tem como objetivo analisar o desempenho de quatro lojas fictícias da rede Alura Store, a fim de identificar qual delas apresenta menor eficiência e deve ser vendida para viabilizar um novo empreendimento.

A análise foi realizada com Python e bibliotecas de Data Science, considerando indicadores de vendas, faturamento, avaliações de clientes, categorias de produtos, produtos mais vendidos e custo médio de frete.

🎯 Objetivo da Análise

Avaliar o desempenho das lojas com base nos seguintes critérios:

Faturamento total

Volume de vendas por categoria

Média de avaliação dos clientes

Produtos mais e menos vendidos

Frete médio por loja

Ao final, foi elaborada uma recomendação baseada nos dados analisados.

📊 Visualização de Dados

Foram criados diferentes tipos de gráficos para facilitar a interpretação dos resultados, incluindo:

Gráfico de barras (faturamento)

Heatmap / gráfico comparativo de categorias

Gráfico de dispersão (frete médio)

Essas visualizações permitiram uma análise mais clara do desempenho das lojas.

✅ Conclusão

Com base nas análises realizadas, a Loja 4 foi identificada como a unidade com menor desempenho geral, apresentando:

menor faturamento total;

menor desempenho em categorias estratégicas;

menor destaque em produtos mais vendidos;

desempenho inferior em relação às demais lojas, mesmo com frete médio mais baixo.

Diante disso, recomenda-se que a Loja 4 seja vendida, pois apresenta menor eficiência comercial e menor potencial de crescimento em comparação às outras unidades da rede.
